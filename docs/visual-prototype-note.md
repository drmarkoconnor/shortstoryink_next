# v1.1 visual prototype

The current branch prototypes the agreed **dark room / illuminated paper** direction while preserving warm, high-legibility manuscript surfaces.

This note exists to make the intent explicit during review:

- dark bottle-green / charcoal application shell
- warm paper working surfaces
- distinct writer and editorial atmospheres
- restrained sage, burgundy and brass accents
- no heavy colour coding
- no course-led writer experience
- invitation-led public positioning

Do not propagate further visual complexity until the writer and editor preview has been reviewed in real use.
