- Replace the small link with a prominent Your projects introduction and Open your projects action.
- Explain that sections, cards, snapshots and compile live inside a project; keep quick submission intact.
- Add Your projects to the writer account menu and keep Writing active on project routes.
- Set WRITER_PROJECTS_ENABLED=true explicitly in Netlify's deploy-preview context, with Builds and Functions scopes. Do not infer function runtime configuration from build-only CONTEXT metadata.
- Set STUDIO_SUPPRESS_EMAIL=true in the same preview scopes and honour it before any mail delivery. Production notification configuration is unchanged.
- No changes to existing drafts, manuscripts, identity records or database migrations.

Direct writer path: `/app/writer/projects`. Create a named project, then add Section or Folder. Project views include Cards, Outline, Read manuscript, Compile manuscript and Snapshots.

Four focused regression tests cover entry-point visibility, disabled state, writer-only navigation wiring and preview email suppression without CONTEXT.
